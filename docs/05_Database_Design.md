# 05 - Database Design

The v2.0 database retains existing raw evidence tables but introduces new relational tables to store normalization, correlation, and reasoning outputs.

## Existing Tables (Unchanged)
- `evidence_items` (raw_data JSON blob)
- `case_metadata`
- `file_hashes`

## New Tables (v2.0)
- **`entities`**: Normalized entities extracted from `evidence_items` (e.g., Process, File, User, Event).
- **`findings`**: Correlated investigation findings generated by the Correlation Engine.
- **`correlations`**: Junction table mapping `entities` or `evidence_items` to `findings`.
- **`confidence_scores`**: The calculated scores and the individual weights contributing to the overall endpoint score.
- **`anti_forensics`**: Alerts generated by the Anti-Forensics detection engine.
- **`attack_chains`**: Ordered sequence of findings representing an attack narrative.
- **`recommendations`**: Suggested actions tied to specific findings.

## Example: Findings Table
```sql
CREATE TABLE findings (
    finding_id TEXT PRIMARY KEY,
    timestamp TEXT,
    severity TEXT,
    confidence_contribution INTEGER,
    title TEXT,
    description TEXT
);
```
